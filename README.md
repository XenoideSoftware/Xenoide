Software Development environment for Games and System Software

## AI Usage Guidelines
- To create support utilities: code generators, checkers, scaffolding, etc.
- To support designing and creating unit tests.
- To perform code review.
- To create native UIs for each platform.
- To discuss different approaches via Q/A sessions.

**IMPORTANT**: All the AI-generated code must pass all the analyzers, checkers, and be paired with a corresponding set of unit tests covering over 90% of the new code.

## Not Allowed Usage
AI might assist here suggesting algorithms, approaches, testing strategies, etc, but rendering, algoriths and any performance-sensitive code **will be implemented by humans**.
