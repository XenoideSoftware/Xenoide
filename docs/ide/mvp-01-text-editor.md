# Abstract

Primer ciclo de iteración, cuyo objetivo es poder iniciar un flujo de trabajo concreto para hacer releases periódicos a medida que se vayan completando los distintos MVPs.

Objetivos que se esperan de esta primera etapa son:

- Preparar una serie de workflows de CI / CD, para facilitar el trabajo de integración y despliegue continuos.
- Iniciar línea de base de código, que pueda soportar posteriormente los distintos desarrollos futuros de forma más fácil.
- Iniciar lineamientos de arquitectura, para que se pueda determinar cómo podría escalar eventualmente este desarrollo.
