# Domain Model

## Glossary
- **Editor**: A *Component* that allows the User to read, modify and navigate code.
- **Editor Manager**: A Component that manages a list of Editors, mapping each one of them to a single Source
- **Filesystem Browser**: A Component that manages 
- **Source**: A source code file that belongs to a Project.
- **Diagnostic**: A description, generated by a Tool that shows information about a concrete *File* location and line, belonging to a *Project*. Intended to be displayed by an UI.
- **Project**: The workspace model, where it references the root folder where the software solution sits, knows how to use the build system, the package manager, the list of artifacts generated, etc.
- **Executable**: Binary artifact file that is generated as a the final result of a Build operation using the Build System. It can be generated with debugging information, and it can be Debugged.
- **Build System**: Specialized toolchain used to group source code files, configuration, options, etc, in order to generate one or more Build Artifacts.
- **Package Manager**: Specialized toolchain used to fetch, compile, install external libraries used as dependencies by the Build Project, and utimately, referenced by the *Project*.
- **Debugger**: Specialized Component used to run an existing executable file in order to follow the code execution path, see variable values in runtime, follow the callstack, setup breakpoints, stop execution when a breakpoint triggers, etc.
